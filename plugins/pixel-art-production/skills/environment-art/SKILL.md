# environment-art

[공통 제작 절차](../../references/pipeline.md)에 따라 게임 설정, 이미지 생성과 검수를 진행한다.

타일맵과 타일시트는 사용자가 결과 이미지에 표기를 명시적으로 요청한 경우에만 글자를 넣는다. 프롬프트와 참조 이미지에 있는 예시 지명, 타일 이름, 라벨, 번호는 배치와 설명을 위한 정보로만 사용한다. 생성 프롬프트에 요청된 표기만 이미지에 넣도록 명시하고, 검수에서 요청하지 않은 글자가 보이면 제거한 뒤 다시 확인한다.

1. 카메라, 타일 크기, 반복 방향, 레이어별 배율과 전경 대비를 작업 명세에 기록한다. 반복 배경이면 양끝이 이어지는 형태를 명세한다.
2. 규격 타일은 프로젝트에 맞는 `tile` 또는 `tile32` 매니페스트로 `split`, `review`, 필요 시 `assemble`을 실행한다. 확대 후보는 먼저 `inspect-grid`로 검사한다.
3. 배경은 실제 화면 비율과 반복 접합부를 게임 배율에서 확인하고, 패럴랙스용 레이어는 개별 PNG로 제공한다. 타일의 접합, 알파와 역할별 색을 확인하고 결과를 기록한다.
4. 반복 지형은 `compose repeat`로 3×3 접합부를 확인한다. 배경 레이어는 같은 화면 크기로 내보내고 `compose layers`로 전경 대비를 확인한다.
