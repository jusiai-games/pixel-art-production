# 캐릭터 동작 제작과 재생 검수

## 생성 전에 키 포즈 정하기

한 번에 동작 하나와 방향 하나를 다룬다. 작업 명세에 같은 방향의 승인 기준 포즈, 프로젝트 고정 프레임과 피벗, 게임에서 실제로 이어지는 시작·종료 포즈, 프레임별 지속 시간(ms), 반복 여부를 적는다. 기존 동작을 고칠 때는 게임의 이벤트와 타이밍을 기준으로 삼는다.

- 걷기는 양쪽 발의 착지와 몸 아래를 통과하는 포즈부터 잡는다. 명세에 지지발을 표시하고, 이동 속도와 보폭을 함께 보면서 접지 중 미끄러짐을 확인한다.
- 공격·시전은 준비, 발동, 회복 포즈를 기준으로 잡는다. 타격이나 주문 이벤트가 연결된 프레임을 표시하고, 준비와 회복에 시간을 배분해 발동 구간이 읽히게 한다.
- 대기는 발과 시선의 기준점을 유지하면서 가슴과 어깨의 작은 호흡부터 검토한다. 옷자락이나 장신구는 필요한 경우 몸통보다 늦게 따라오도록 타이밍을 잡는다.

키 포즈를 먼저 비교한 뒤, 동작이 건너뛰어 보이는 구간에 중간 포즈를 추가한다. 새 후보에는 같은 방향의 승인 포즈와 바로 앞뒤 키 포즈를 참고 자료로 제공한다. 시트로 생성한다면 상태와 방향 하나만 한 줄에 두고, 포즈 사이에 분리할 여백을 남긴다. 규칙 격자가 확인된 입력은 `split` 경로를 사용한다. 격자가 불규칙하면 포즈를 개별 PNG로 분리한 뒤 같은 캔버스와 발 기준을 적용한다. 점프나 몸을 낮추는 동작의 의도된 이동은 보존한다.

## 검수한 PNG를 재생하기

`review`를 통과한 개별 PNG를 **재생 순서대로** 넘긴다. 프로젝트 팔레트와 프레임 규격을 적용해 투명한 애니메이션 PNG 미리보기 두 장(1배, 최근접 4배)과 프레임별 타이밍 보고서를 `work/`에 저장한다. 아래는 제자리 대기 루프의 예다. 한 번 재생하는 동작은 `--loop`를 생략한다.

```powershell
& $py $tool preview-motion "$game/palettes/project.json" "$game/work/idle-motion-01" `
  "$run/frames/hero_idle_down_00.png" "$run/frames/hero_idle_down_01.png" "$run/frames/hero_idle_down_02.png" `
  --durations 180 100 140 --loop
```

- 1배와 게임의 목표 배율에서 발 미끄러짐, 몸통과 장비의 갑작스러운 이동, 방향·손잡이·광원 변화를 확인한다. 반복 동작은 마지막에서 처음으로 넘어가는 순간까지 본다.
- `report.json`의 `identical_pairs_1_based`에는 같은 픽셀의 연속 프레임 쌍을 재생 순서에 따른 1부터 시작하는 번호로 기록한다. 반복에서는 마지막과 처음도 검사한다. 의도한 정지는 유지하고, 의도하지 않은 중복이나 루프의 멈칫거림은 포즈 또는 지속 시간을 수정해 다시 재생한다.
- 수정한 구간을 다시 검수하고 실제 경계 프레임을 [상태 전환 맵](pipeline.md#상태-전환-검수)에 기록한다. 플레이어 입력, 이동 속도와 발동 타이밍이 적용된 게임 화면에서 확인한 뒤 최종 PNG를 승인한다.

동작별 제작과 재생 검수 방식은 [sprite-gen](https://github.com/aldegad/sprite-gen)에서 참고했다.
