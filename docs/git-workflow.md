# 플러그인과 게임 아트 관리

이 저장소는 플러그인 코드, 제작 스킬, 공용 문서와 템플릿을 관리한다. 공용 변경은 별도 브랜치에서 커밋하고 플러그인을 갱신해 각 게임 작업 공간에서 사용한다.

에이전트는 사용자 지정 위치나 게임의 기존 아트 폴더를 사용한다. 새 작업 폴더의 선택 기준은 [제작 절차](../plugins/pixel-art-production/references/pipeline.md#게임-아트-작업-폴더)를 따른다.

| 파일 | 관리 위치 |
| --- | --- |
| 제작 스킬, CLI, 템플릿, Unity 임포터 | 플러그인 저장소 |
| 게임의 레퍼런스, 팔레트, 매니페스트, 프롬프트, 검수 결과와 승인 PNG | 게임 아트 작업 폴더. 버전 관리와 백업은 게임별 정책을 따른다. |
| Unity에 반영한 PNG, `.sprite.json`, `.meta` | 게임의 Unity 저장소에서 함께 추적 |

플러그인을 갱신한 뒤에도 같은 게임 아트 작업 폴더에서 작업을 이어간다. 새 템플릿의 항목이 필요하면 기존 설정에 해당 항목을 반영한다.
