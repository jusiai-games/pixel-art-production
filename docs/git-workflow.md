# 클론과 공용 업데이트

게임마다 같은 공용 원격을 클론한다. 도구 개선은 공용 브랜치에 합치고, 게임 클론은 그 원격의 기본 브랜치를 당겨 온다.

```sh
git clone <pipeline-url> game-a-art
cd game-a-art
git pull --ff-only
```

`--ff-only`는 로컬 브랜치가 갈라졌으면 중단한다. 공용 개선 작업은 별도 브랜치에서 커밋하고 공용 원격에 병합한 후 각 게임 클론의 기본 브랜치를 갱신한다. 게임별 설정을 공용 템플릿에 넣으면 클론 사이에 충돌이 생기므로 `project/game/`에서 수정한다.

| 위치 | 버전 관리 |
| --- | --- |
| `AGENTS.md`, `CLAUDE.md`, `docs/`, `tools/`, `unity/` | 공용 도구 원격 |
| `project/game/` | 클론 로컬. 레퍼런스·생성물·팔레트·매니페스트·프롬프트와 승인 이력을 함께 백업 |
| Unity에 반영한 PNG, `.sprite.json`, `.meta` | 게임의 Unity 저장소에서 함께 추적 |

Git 제외는 백업을 제공하지 않는다. 다른 컴퓨터에서 아트 작업을 이어갈 때는 `project/game/`을 게임별 백업에서 복원한다. 공용 도구를 갱신할 때 초기화를 다시 실행할 필요는 없다. 기존 게임에 필요한 템플릿 변경은 새 템플릿을 참고해 해당 게임 설정에 반영한다.

이 구조를 이미 Git이 추적하는 복사본에 적용한다면 최초 정리 커밋에서 이전 파일들의 추적 제거 여부를 확인한다. `.gitignore`는 이미 추적 중인 파일에 소급 적용되지 않는다. 기존 파일이 원격 이력에 있다면 이 정리로 과거 커밋에서 사라지지 않는다.

AI 작업은 루트에서 시작한다. Codex는 `AGENTS.md`, Claude Code는 이를 가져오는 `CLAUDE.md`를 읽는다. 자동으로 읽지 않는 도구에서는 첫 요청에 루트의 `AGENTS.md`를 읽도록 지정한다.
